
## Как запустить

1. Скачать/скопировать все файлы проекта
2. Открыть файл `index.html` в браузере (Chrome/Firefox/Edge)
3. Готово! Данные сохраняются автоматически

## Используемые конструкции JavaScript

- Работа с массивами и объектами
- Модульный подход (отдельные файлы)
- DOM-манипуляции
- localStorage
- Валидация форм
- Алгоритмы сортировки и фильтрации
- Генерация случайных чисел для розыгрыша
